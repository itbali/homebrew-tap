# itbali/homebrew-tap

Пакеты Homebrew для приложений [itbali](https://github.com/itbali).

```bash
brew install --cask itbali/tap/raskladushka
```

| Пакет | Что это |
| --- | --- |
| `raskladushka` | [Раскладушка](https://github.com/itbali/raskladushka) — исправляет текст, набранный не в той раскладке, и переключает язык. macOS 13+. |
